🚀 HOW TO TEST LOCALLY
================================================================================

1. SETUP:
   cd crm-frontend
   npm install  # (if needed)

2. START BACKEND (if not running):
   cd crm-backend
   mvn spring-boot:run
   # Should be running on http://localhost:8080

3. START FRONTEND:
   cd crm-frontend
   npm run dev
   # Should be running on http://localhost:5173

4. LOGIN:
   • Go to http://localhost:5173
   • Register or login with test account

5. TEST LEAD MAGNETS:
   • In sidebar, click "Marketing" → "Lead Magnets"
   • You should see the list page
   • Click "New Campaign" to create one
   • Click on campaign to see details

6. TEST PUBLIC FORM:
   • From list or details page, click "Copy" or "Open Public"
   • Visit the public URL (e.g., http://localhost:5173/m/TOKEN/slug)
   • Fill out form and submit
   • Should see success screen

🐛 IF YOU FIND ISSUES
================================================================================

Common Issues & Solutions:

1. "Page not found" for /marketing/lead-magnets
   → Check that routes are added to App.jsx
   → Check that Sidebar has Marketing section
   → Restart dev server: npm run dev

2. API calls returning 401 (unauthorized)
   → Check that JWT token is in localStorage
   → Re-login to app
   → Check backend is running

3. Form not submitting
   → Check browser console for errors
   → Verify API endpoint is correct
   → Check network tab for API requests

4. Images/icons not showing
   → Check that lucide-react is installed
   → Clear browser cache
   → Restart dev server

5. Dark mode not working
   → Check that theme toggle is working
   → Verify dark: classes are in Tailwind config
   → Check html element has 'dark' class

📞 HOW TO REPORT ISSUES
================================================================================

When reporting an issue, include:

1. What you were trying to do
2. What happened (error message if any)
3. What you expected to happen
4. Steps to reproduce
5. Browser/OS information
6. Screenshots (if possible)

Example:
"When I try to create a campaign with name 'Test' and slug 'test-slug',
I get error 'Network Error' in toast. Expected: Campaign created successfully.
Browser: Chrome 126, OS: Windows 11. Steps: 1) Click New Campaign 2) Enter
data 3) Click Save"

🎓 KEY CONCEPTS
================================================================================

AUTO-SLUG GENERATION:
  • Converts name to lowercase
  • Replaces spaces with hyphens
  • Removes special characters
  • Max 100 characters
  • Example: "Free CRM Guide 2024!" → "free-crm-guide-2024"

SLUG VALIDATION:
  • Checks if slug is already in use
  • Uses API endpoint with debounce
  • Shows available/in-use status
  • Real-time feedback

DARK MODE:
  • Tailwind's dark: prefix
  • Toggle in settings
  • Persisted to localStorage
  • Applied globally via HTML class

PERMISSIONS:
  • OWNER: Full access
  • ADMIN: Full access
  • MEMBER: Read-only
  • PUBLIC: Anonymous form submission

RESPONSIVE DESIGN:
  • Mobile: 320px+
  • Tablet: 768px+
  • Desktop: 1024px+
  • Tailwind breakpoints (sm, md, lg, xl)
