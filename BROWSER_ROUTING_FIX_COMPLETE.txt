Successfully implemented fix for BROWSER test case routing bug in standalone 
Chrome Extension test run execution. BROWSER test cases now correctly route to 
the Playwright browser runner client instead of incorrectly routing to the API 
executor.

Bug Root Cause:
- executeTestRun() called executeSingleTestCase() for ALL test types without checking testType
- BROWSER test cases have browser automation steps, NOT API endpoints
- This caused "Endpoint URL cannot be empty" errors (~130-140 second timeouts)

Fix Implemented:
- Added testType-based routing: BROWSER → browser runner, API_CRUD → API executor
- Extracted executeBrowserTestCase() method reusing suite execution logic
- Preserved all existing API_CRUD behavior, cancellation, persistence, counters

IMPLEMENTATION DETAILS
================================================================================

### 1. ChromeExtensionRunnerClient Dependency Injection

Added to constructor injection via @RequiredArgsConstructor:
```java
private final ChromeExtensionRunnerClient runnerClient;
```

This enables communication with the Playwright runner service for browser test execution.

### 2. TestType-Based Routing Logic

Modified executeTestRun() execution loop (lines 130-137):
```java
ChromeExtensionTestResult result;

// Route based on testType: BROWSER → browser runner, otherwise → API executor
if (tc.getTestType() == com.arjun.crm.enums.TestCaseType.BROWSER) {
    result = executeBrowserTestCase(workspaceId, extension, testRun, tc, effectiveToken, runLogs);
} else {
    result = executeSingleTestCase(workspaceId, extension, testRun, tc, effectiveToken, runLogs);
}
```

Impact:
- BROWSER tests: Execute through browser runner (Playwright)
- API_CRUD, STORAGE_CRUD, DOM_INJECTION, INTEGRATION: Continue through executeSingleTestCase() unchanged

### 3. executeBrowserTestCase() Method Implementation

New method (lines 365-588) that:
1. Generates unique child runner ID
2. Extracts browser steps from test case configuration
3. Builds BrowserTestRunRequest with steps
4. Calls runnerClient.startBrowserRun() to start Playwright execution
5. Polls runnerClient.getBrowserRunStatus() until completion (30s timeout)
6. Handles cancellation during execution
7. Maps browser runner response to ChromeExtensionTestResult
8. Preserves error handling and logging patterns

Reuses patterns from ChromeExtensionSuiteExecutionServiceImpl.executeBrowserSuiteItem() for consistency.

### 4. generateChildRunnerId() Helper Method

Simple helper to generate unique runner IDs:
```java
private long generateChildRunnerId(Long testRunId, Long testCaseId) {
    return System.currentTimeMillis() + (testRunId * 10000L) + testCaseId;
}
```
