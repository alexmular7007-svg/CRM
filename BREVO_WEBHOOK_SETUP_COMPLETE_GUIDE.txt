STEP-BY-STEP WEBHOOK SETUP IN BREVO
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Log in to Brevo
───────────────────────

1. Open: https://www.brevo.com
2. Click "Sign In" (top right)
3. Enter your email and password
4. Click "Sign In"


STEP 2: Navigate to Webhooks Section
─────────────────────────────────────

After logging in, look for one of these paths:

PATH A (Most Common):
  1. Click your name/profile (top right)
  2. Click "Account Settings"
  3. Look for "Webhooks" in left sidebar
  4. Click "Webhooks"

PATH B (Alternative):
  1. Look for "Settings" icon or menu
  2. Click "SMTP & API"
  3. Look for "Webhooks" tab
  4. Click "Webhooks"

PATH C (If still can't find):
  1. Search in Brevo for "webhooks"
  2. Or go directly to: https://app.brevo.com/webhook
  3. You should see webhook configuration page


STEP 3: Create New Webhook
──────────────────────────

On the Webhooks page, look for a button like:
  - "Add webhook"
  - "Create webhook"
  - "New webhook"
  - "Configure webhook"

Click this button.


STEP 4: Fill in Webhook URL
────────────────────────────

You'll see a form with a field like "Webhook URL" or "Endpoint URL"

PASTE THIS EXACT URL:

https://crm-production-932d.up.railway.app/api/webhooks/brevo


IMPORTANT:
  ✓ Must be HTTPS (not HTTP)
  ✓ Must be exact domain: crm-production-932d.up.railway.app
  ✓ Must include: /api/webhooks/brevo
  ✓ No trailing slash at the end


STEP 5: Select Events to Track
───────────────────────────────

You'll see a list of email events with checkboxes. SELECT THESE:

REQUIRED (Must select):
  ✅ DELIVERED
  ✅ OPENED
  ✅ CLICKED

RECOMMENDED (Optional but good):
  ✅ BOUNCE
  ✅ SOFT_BOUNCE
  ✅ SPAM
  ✅ UNSUBSCRIBE
  ✅ REPLY

Leave unchecked (not needed):
  ❌ SENT (we handle this client-side)
  ❌ RENDERED (we don't need this)

At minimum, check: DELIVERED, OPENED, CLICKED


STEP 6: Save/Create the Webhook
────────────────────────────────

Look for a button like:
  - "Save"
  - "Create"
  - "Add webhook"
  - "Confirm"

Click this button.

EXPECTED RESULT:
  ✓ You'll see a success message
  ✓ Webhook URL will show in list
  ✓ Status might show "Active" or "Enabled"

TROUBLESHOOTING: IF STILL NOT WORKING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: Webhook saved but analytics still show 0 delivered
───────────────────────────────────────────────────────────

Possible causes:

1. BREVO WEBHOOK NOT ACTUALLY ENABLED
   Solution:
   - Go back to Brevo webhook settings
   - Verify webhook shows "Active" status (not "Disabled")
   - Check URL is exactly: https://crm-production-932d.up.railway.app/api/webhooks/brevo
   - Check DELIVERED event is checked
   - Re-save if needed

2. BACKEND NOT RUNNING
   Solution:
   - Check Railway dashboard
   - Is Backend service running? (should show green/active)
   - Check logs for errors
   - If down, it will need to be redeployed

3. WEBHOOK URL NOT REACHING BACKEND
   Solution:
   - Test from terminal (ask for instructions)
   - Check if backend logs show webhook reception
   - Verify HTTPS certificate is valid

4. WRONG CAMPAIGN ID IN METADATA
   Solution:
   - Should be automatically correct
   - If not, check email sending code sends campaign_id in metadata

5. DATABASE NOT UPDATING
   Solution:
   - Webhooks might be arriving but database update failing
   - Check backend logs for errors
   - Verify email_campaign_recipients table exists
