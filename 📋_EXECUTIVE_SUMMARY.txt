🔐 HOW OAUTH2 WORKS:
====================

User Experience Flow:
  1. User clicks "Sign in with Google"
  2. Browser redirects to Google login
  3. User enters credentials
  4. Google asks for permissions
  5. User approves
  6. Google sends auth code back to your app
  7. Your backend exchanges code for JWT token
  8. Frontend receives JWT and loads user profile
  9. User is logged in and sees dashboard ✅

Technical Flow:
  Frontend → Google → User → Google → Backend → Frontend → Dashboard

Why it's secure:
  ✓ User credentials never leave Google servers
  ✓ Your app never sees password
  ✓ Backend validates everything
  ✓ JWT token is time-limited
  ✓ Only trusted OAuth providers allowed

🆘 TROUBLESHOOTING:
===================

Problem: CORS Error
Solution: Check Railway CORS_ALLOWED_ORIGINS is set
          Wait 2-5 minutes for redeploy
          Hard refresh browser (Ctrl+Shift+R)

Problem: OAuth provider says redirect_uri mismatch
Solution: Check Google Console or GitHub OAuth settings
          Make sure URL matches exactly (case-sensitive)
          No trailing slashes or spaces

Problem: Backend not responding
Solution: Check Railway dashboard - is service running?
          Check Railway logs for errors
          Verify database connection

Problem: User profile not loading
Solution: Check browser DevTools console for errors
          Check Railway logs for backend errors
