  ERROR: update or delete on table "chat_messages"
  violates foreign key constraint on table "attachments"
  
Root Cause: Incorrect FK dependency deletion order
Impact: Workspace deletion failed completely in production


THE SOLUTION
═══════════════════════════════════════════════════════════════════════════════
Implemented 7-phase correct FK dependency deletion order:

  PHASE 1: Delete ALL attachments (chat + task)          ← CRITICAL FIX
  PHASE 2: Delete task-related data (mentions, comments)  ← CRITICAL FIX
  PHASE 3: Delete lead-related data
  PHASE 4: Delete chat-related data (now safe - attachments gone)
  PHASE 5: Delete project-related data
  PHASE 6: Delete workspace metadata
  PHASE 7: Delete workspace root entity

Result: All FK constraints properly ordered, no violations possible
