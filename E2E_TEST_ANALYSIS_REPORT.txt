COMMON FAILURE CAUSES & DIAGNOSTICS
═══════════════════════════════════════════════════════════════════════════════

Symptom: Response data.bodyPlainText is empty/null
Cause 1: AI model returned JSON without "body" field
  Solution: Check Groq API response format, verify system message
Cause 2: AI model returned parsing failed
  Solution: Check exception in service logs, verify JSON parsing logic
Cause 3: AI response timeout
  Solution: Increase timeout in application.yml (ai.xai.timeout)

Symptom: Response data.bodyHtml does not contain <html> tags
Cause: generateHtmlEmail() method not executed or failed
  Solution: Check service logs for exceptions in HTML generation

Symptom: CTA URL not preserved in HTML
Cause: Malformed URL in request, URL escaping issue
  Solution: Verify URL format in request, check escapeHtml() method

Symptom: HTTP 500 error instead of 200
Cause: Unhandled exception in controller/service
  Solution: Check backend logs for stack trace

Symptom: HTTP 400 with validation error
Cause: AIEmailGenerationRequest validation failed
  Solution: Verify all @NotBlank fields are present, tone matches allowed values
