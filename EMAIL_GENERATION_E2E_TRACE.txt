## EXECUTION FLOW DIAGRAM

HTTP Request (POST /api/emails/generate)
  ↓
AIEmailGenerationController.generateEmail()
  ├─ Validates AIEmailGenerationRequest
  ├─ Returns HTTP 400 if invalid
  └─ Calls emailGenerationService.generateEmail(request)
  
AIEmailGenerationServiceImpl.generateEmail()
  ├─ Constructs prompt from request fields
  ├─ Calls xaiProvider.generateResponseNoCache(prompt)
  ├─ Receives AIResponse(content, success, model, error)
  ├─ Parses AIResponse.content as JSON
  ├─ Extracts subject and body fields
  ├─ Validates length limits (subject<256, body<5000)
  ├─ Generates HTML email from plain text
  └─ Returns AIEmailGenerationResponse

XAIProvider.generateResponseNoCache()
  ├─ Builds OpenAI-format request
  ├─ Sets: model="llama-3.3-70b-versatile"
  ├─ Sets: Authorization: Bearer <XAI_API_KEY>
  ├─ POST to: https://api.groq.com/openai/v1/chat/completions
  ├─ Receives OpenAI-format response
  ├─ Parses: choices[0].message.content
  ├─ Retry: max 3 attempts with exponential backoff
  └─ Returns: AIResponse

## ERROR HANDLING

Failure Scenario 1: Request Validation Fails
- HTTP Status: 400 Bad Request
- Example: empty purpose field, invalid tone, malformed URL
- Response: Spring validation error details

Failure Scenario 2: AI Provider Timeout
- HTTP Status: 200 OK
- Response.data.success: false
- Response.data.error: "AI service request timed out"
- Cause: Groq API slow response (>30s)

Failure Scenario 3: AI Provider Rate Limited
- HTTP Status: 200 OK
- Response.data.success: false
- Response.data.error: "AI service rate limit exceeded"
- Cause: >30 requests/minute (Groq free tier)

Failure Scenario 4: AI Provider Unavailable
- HTTP Status: 200 OK
- Response.data.success: false
- Response.data.error: "AI service is currently unavailable"
- Cause: Groq API down, credentials invalid, or network issue

Failure Scenario 5: Malformed AI Response
- HTTP Status: 200 OK
- Response.data.success: false
- Response.data.error: "AI service returned invalid data format"
- Cause: AI response not valid JSON or missing required fields
