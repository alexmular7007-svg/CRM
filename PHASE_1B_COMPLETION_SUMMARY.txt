DATABASE SCHEMA VERIFIED
================================================================================

lead_magnets Table:
  - id (BIGSERIAL PRIMARY KEY)
  - workspace_id (BIGINT NOT NULL) - FK to workspaces
  - name (VARCHAR(255) NOT NULL) - Campaign name
  - description (TEXT) - Campaign description
  - slug (VARCHAR(100) NOT NULL) - URL slug
  - public_token (VARCHAR(36) NOT NULL UNIQUE) - Public form identifier
  - is_active (BOOLEAN NOT NULL DEFAULT true) - Campaign status
  - created_by_id (BIGINT NOT NULL) - FK to users
  - created_at (TIMESTAMP WITH TIME ZONE NOT NULL) - Creation time
  - updated_at (TIMESTAMP WITH TIME ZONE NOT NULL) - Last update time
  
  Constraints:
    - PRIMARY KEY: id
    - FOREIGN KEY: workspace_id -> workspaces
    - FOREIGN KEY: created_by_id -> users
    - UNIQUE: public_token
    - UNIQUE: (workspace_id, slug)

lead_magnet_submissions Table:
  - id (BIGSERIAL PRIMARY KEY)
  - lead_magnet_id (BIGINT NOT NULL) - FK to lead_magnets
  - lead_id (BIGINT) - Optional FK to leads
  - name (VARCHAR(255) NOT NULL) - Submitter name
  - email (VARCHAR(255) NOT NULL) - Submitter email
  - phone (VARCHAR(50)) - Optional phone
  - company (VARCHAR(255)) - Optional company
  - session_token_hash (VARCHAR(64) NOT NULL) - Session deduplication
  - referrer (TEXT) - HTTP referrer
  - custom_fields (JSONB) - Custom form fields
  - submitted_at (TIMESTAMP WITH TIME ZONE NOT NULL) - Submission time
  - updated_at (TIMESTAMP WITH TIME ZONE NOT NULL) - Last update time
  
  Constraints:
    - PRIMARY KEY: id
    - FOREIGN KEY: lead_magnet_id -> lead_magnets (ON DELETE CASCADE)
    - FOREIGN KEY: lead_id -> leads (ON DELETE SET NULL)

lead_magnet_views Table:
  - id (BIGSERIAL PRIMARY KEY)
  - lead_magnet_id (BIGINT NOT NULL) - FK to lead_magnets
  - session_token_hash (VARCHAR(64) NOT NULL) - Session tracking
  - referrer (TEXT) - HTTP referrer
  - viewed_at (TIMESTAMP WITH TIME ZONE NOT NULL) - View time
  
  Constraints:
    - PRIMARY KEY: id
    - FOREIGN KEY: lead_magnet_id -> lead_magnets (ON DELETE CASCADE)

Indexes (18 Total):
  - 5 on lead_magnets (workspace_id, public_token, is_active, created_at, workspace+slug)
  - 6 on lead_magnet_submissions (magnet_id, lead_id, session, magnet+email, submitted_at, magnet+submitted)
  - 5 on lead_magnet_views (magnet_id, session, viewed_at, magnet+viewed, session+viewed)
  - 1 on leads (source_magnet_id)
