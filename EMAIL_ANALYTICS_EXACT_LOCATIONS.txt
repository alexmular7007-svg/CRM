📍 FILE: crm-backend/src/main/java/com/arjun/crm/service/impl/EmailAnalyticsServiceImpl.java

CLASS: EmailAnalyticsServiceImpl (implements EmailAnalyticsService)

KEY METHOD: processWebhookEvent()
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1: Validate webhook payload
STEP 2: Check for duplicate events using providerEventId
STEP 3: Extract campaign_id and recipient_id from metadata
STEP 4: Load campaign and recipient from database
STEP 5: Update recipient status and timestamps based on event:
        - DELIVERED → deliveredAt = now
        - OPENED → openedAt = now
        - CLICKED → clickCount++, lastClickedAt = now
        - BOUNCED → bounceType = HARD_BOUNCE or SOFT_BOUNCE
        - UNSUBSCRIBED → unsubscribedAt = now
STEP 6: Save recipient with new status
STEP 7: Create EmailCampaignHistory record (audit trail)
STEP 8: Update campaign metrics:
        - sentCount++
        - deliveredCount++
        - openedCount++
        - clickedCount++
        - bouncedCount++
STEP 9: Save campaign with updated metrics
