🔐 OAuth Flow Explained:
=======================

User clicks "Sign in with Google":
  1. Frontend redirects to: accounts.google.com/oauth2/auth?...
  2. User logs in at Google
  3. Google redirects to: https://ai-crmsite.vercel.app/oauth2/callback?code=...
  4. Frontend calls backend: /login/oauth2/code/google?code=...
  5. Backend exchanges code for access token
  6. Backend gets user info and creates JWT
  7. Backend redirects: https://ai-crmsite.vercel.app/oauth2/callback?token=JWT
  8. Frontend loads user profile with JWT
  9. User redirected to dashboard ✅

Same flow for GitHub, just different OAuth provider.


💡 Key Points:
==============

✓ Frontend redirect URI: Must match what's in Google/GitHub console
✓ Backend OAuth endpoints: Hidden from OAuth providers (internal)
✓ CORS: Must allow your frontend domain at backend
✓ WebSocket: Also needs CORS update
✓ Auto-redirect: Frontend auto-detects window.location.origin
