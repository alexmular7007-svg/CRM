                  TEST 8: ANALYTICS RATE CALCULATIONS
================================================================================

OBJECTIVE: Verify analytics rates calculated correctly

SCENARIO:
  Recipients: 1
  Delivered: 1
  Opened: 1 (if pixel loaded)
  Clicked: 1 (from test)

CALCULATIONS:
  Delivery Rate = (Delivered / Recipients) * 100 = (1/1)*100 = 100%
  Open Rate = (Opened / Delivered) * 100 = (1/1)*100 = 100%
  Click Rate = (Clicked / Delivered) * 100 = (1/1)*100 = 100%

VERIFICATION:
  1. Navigate to campaign analytics page
  2. VERIFY DISPLAYED RATES:
     - Delivery Rate: 100%
     - Open Rate: 100%
     - Click Rate: 100%
  3. Verify progress bars:
     - Each bar at 100% width
     - Colors correct (green, blue, purple)
  4. Query database to confirm:
     SELECT 
       COUNT(*) as recipients,
       COUNT(delivered_at) as delivered,
       COUNT(opened_at) as opened,
       COUNT(first_clicked_at) as clicked
     FROM email_campaign_recipients
     WHERE campaign_id = {campaign_id}
  5. Manual calculation:
     Delivery Rate: delivered / recipients * 100
     Open Rate: opened / delivered * 100
     Click Rate: clicked / delivered * 100
  6. Compare calculated vs displayed

EXPECTED RESULTS:
  ✓ Display rates match calculated rates
  ✓ Progress bars accurate
  ✓ Database query confirms counts
  ✓ No off-by-one errors
  ✓ Rates update correctly
