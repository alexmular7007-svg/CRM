🔟 IF SOMETHING GOES WRONG
==========================

CORS Error:
  1. Check Railway: CORS_ALLOWED_ORIGINS=https://ai-crmsite.vercel.app
  2. Wait 2-5 minutes for Railway to redeploy
  3. Hard refresh browser (Ctrl+Shift+R)

OAuth Provider Error:
  1. Check Google Console - redirect URI must match exactly
  2. Check GitHub OAuth App - callback URL must match exactly
  3. Make sure new Vercel URL is added (not just old one)

Database Connection Error:
  1. Check DATABASE_PASSWORD is complete: TASKFLOWCRM@#12345
  2. Check Supabase circuit breaker isn't active
  3. Wait 10-15 minutes if circuit breaker is active

Frontend not loading:
  1. Check Vercel deployment succeeded
  2. Check Vercel environment variables are set
  3. Hard refresh browser (Ctrl+Shift+R)

Backend not responding:
  1. Check Railway service is running
  2. Check Railway deployment logs
  3. Verify database connection is working
