================================================================================
                        TRACKING ENDPOINTS
================================================================================

CLICK TRACKING:
  GET /api/campaigns/track/click
  Parameters: campaignId, recipientId, redirect (URL encoded)
  Response: 302 redirect to original URL
  Database: Updates firstClickedAt, lastClickedAt, clickCount
  
OPEN TRACKING:
  GET /api/campaigns/track/open
  Parameters: campaignId, recipientId
  Response: 200 OK with 1x1 GIF pixel
  Database: Updates openedAt (first open only)

================================================================================
                        DATABASE UPDATES
================================================================================

email_campaign_recipients:
  - sentAt: When email sent
  - deliveredAt: When email delivered
  - openedAt: When email opened (first time only)
  - firstClickedAt: First click timestamp
  - lastClickedAt: Most recent click timestamp
  - clickCount: Number of clicks
  - status: PENDING > SENT > DELIVERED > OPENED > CLICKED

email_campaign_history:
  - Audit log of all events
  - Records created for: SENT, DELIVERED, OPENED, CLICKED, BOUNCE
  - Provider event ID prevents duplicates

email_campaigns:
  - sentCount: Total sent
  - deliveredCount: Count where deliveredAt NOT NULL
  - openedCount: Count where openedAt NOT NULL
  - clickedCount: Count where firstClickedAt NOT NULL

================================================================================
                        ANALYTICS CALCULATION
================================================================================

Recipients = Total sent
Delivered = Count where deliveredAt is not null
Opened = Count where openedAt is not null
Clicked = Count where firstClickedAt is not null

Delivery Rate = (Delivered / Recipients) * 100
Open Rate = (Opened / Delivered) * 100
Click Rate = (Clicked / Delivered) * 100

All calculated from database timestamps, not guesses.
Both Brevo webhook + server-side tracking combined for accuracy.
