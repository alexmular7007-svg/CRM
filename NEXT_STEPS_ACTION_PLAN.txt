COMMON ISSUES & FIXES:
======================

Problem: "CORS error" or "redirect_uri mismatch"
Solution:
  1. Check Google Console has your Vercel URL
  2. Check GitHub OAuth has your Vercel URL
  3. Check Railway CORS_ALLOWED_ORIGINS is set
  4. Wait 2-5 minutes for Railway redeploy
  5. Hard refresh browser (Ctrl+Shift+R)

Problem: "Backend not responding"
Solution:
  1. Check Railway deployment status
  2. Check Railway logs for errors
  3. Verify database connection is working
  4. If database error, wait 10-15 minutes (circuit breaker)

Problem: "User profile not loading"
Solution:
  1. Check backend is running
  2. Check DATABASE_PASSWORD is complete: TASKFLOWCRM@#12345
  3. Check in Railway logs for database errors

Problem: "Page keeps redirecting"
Solution:
  1. Check OAuth provider settings match Vercel URL
  2. Check backend OAUTH2_REDIRECT_URI is set correctly
  3. Check CORS_ALLOWED_ORIGINS is set correctly
