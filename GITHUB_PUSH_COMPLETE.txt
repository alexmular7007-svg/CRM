SUPPORT & TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Webhook Not Received:
  • Check webhook URL in Brevo dashboard
  • Verify endpoint is publicly accessible
  • Check application logs: tail -f logs/crm-backend.log
  • Look for: "[BrevoWebhookController] Received webhook"

Analytics Not Displaying:
  • Check if campaign has been sent
  • Verify recipients have been added
  • Check browser console for API errors
  • Verify analytics endpoint responds: GET /api/workspaces/{id}/email-campaigns/{id}/analytics

Database Migration Failed:
  • Check database connection
  • Verify V16 migration file exists
  • Check Flyway migration history table
  • Run migration manually if needed

Performance Issues:
  • Check database indexes (V16 creates indexes)
  • Monitor webhook processing time (should be <500ms)
  • Check React Query cache settings
  • Monitor backend logs for slow queries
