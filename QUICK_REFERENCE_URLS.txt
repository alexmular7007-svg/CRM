STEP-BY-STEP GOOGLE OAUTH TEST:
================================
1. Click: https://ai-crmsite.vercel.app/login → "Sign in with Google"
2. Redirect to: https://accounts.google.com/o/oauth2/v2/auth?client_id=...
3. Enter Google credentials
4. Approve permissions
5. Redirect to: https://accounts.google.com/... (internal redirect)
6. Finally redirect to: https://ai-crmsite.vercel.app/oauth2/callback?code=...
7. Frontend exchanges code with backend
8. Backend generates JWT
9. Redirect to: https://ai-crmsite.vercel.app/oauth2/callback?token=...
10. Frontend loads profile
11. Redirect to: https://ai-crmsite.vercel.app/dashboard ✅


STEP-BY-STEP GITHUB OAUTH TEST:
================================
1. Click: https://ai-crmsite.vercel.app/login → "Sign in with GitHub"
2. Redirect to: https://github.com/login/oauth/authorize?client_id=...
3. Enter GitHub credentials (if not logged in)
4. Approve permissions
5. Redirect to: https://ai-crmsite.vercel.app/oauth2/callback?code=...
6. Frontend exchanges code with backend
