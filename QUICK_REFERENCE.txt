                      FEATURES
================================================================================

1. Click Tracking
   - Records when user clicks CTA
   - Redirects to original URL
   - User sees destination
   - System records click
   - Updates: firstClickedAt, lastClickedAt, clickCount

2. Open Tracking
   - Invisible pixel in email
   - Loads when email opened
   - Records open timestamp
   - First open only (not multiple opens)
   - Updates: openedAt, status

3. Email HTML
   - Renders beautiful emails
   - CTA button with tracking URL
   - Open tracking pixel injected
   - Proper CSS styling

4. Analytics Dashboard
   - Campaign metadata
   - Main metrics cards
   - Rate cards (Delivery, Open, Click) with progress bars
   - Recipient activity table
   - Events breakdown
   - Campaign timeline
   - Responsive (mobile/tablet/desktop)

5. Dual Tracking
   - Server-side tracking (new)

   - Combined accuracy
