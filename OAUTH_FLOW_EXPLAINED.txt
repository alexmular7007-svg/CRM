HOW IT WORKS - STEP BY STEP:
═════════════════════════════

Step 1: User clicks "Sign in with Google"
┌─────────────────────────────────────────────────────────┐
│ Frontend: https://ai-crmsite.vercel.app/login           │
│ User clicks button                                      │
└─────────────────────────────────────────────────────────┘
                      ↓

Step 2: Frontend tells Google where to send user back
┌─────────────────────────────────────────────────────────┐
│ Frontend redirects to Google with:                      │
│ redirect_uri=https://ai-crmsite.vercel.app/oauth2/callback
│ ↑ This URL must match Google Console setting!          │
└─────────────────────────────────────────────────────────┘
                      ↓

Step 3: Google checks if redirect_uri is allowed
┌─────────────────────────────────────────────────────────┐
│ Google Console checks:                                  │
│ Is "https://ai-crmsite.vercel.app/oauth2/callback"    │
│ in the authorized list?                                │
│ ✓ YES → Continue                                        │
│ ❌ NO → Reject login                                     │
└─────────────────────────────────────────────────────────┘
                      ↓

Step 4: User logs in at Google
┌─────────────────────────────────────────────────────────┐
│ https://accounts.google.com                            │
│ User enters credentials                                │
│ User approves permissions                              │
└─────────────────────────────────────────────────────────┘
                      ↓

Step 5: Google sends authorization CODE back to Vercel
┌─────────────────────────────────────────────────────────┐
│ Google redirects to:                                    │
│ https://ai-crmsite.vercel.app/oauth2/callback?code=ABC123
│ ↑ This is VERCEL frontend URL                          │
│ ↑ Railway backend is NOT involved here                 │
└─────────────────────────────────────────────────────────┘
                      ↓

Step 6: Frontend receives code and calls BACKEND
┌─────────────────────────────────────────────────────────┐
│ Frontend (Vercel) calls Backend (Railway):             │
│ POST https://crm-production-932d.up.railway.app/      │
│     login/oauth2/code/google?code=ABC123              │
│ ↑ Now Railway URL is used (but NOT for OAuth redirect) │
└─────────────────────────────────────────────────────────┘
                      ↓

Step 7: Backend exchanges code for access token
┌─────────────────────────────────────────────────────────┐
│ Backend (Railway) calls Google:                        │
│ Google, here's my code: ABC123                         │
│ Google: ✓ Code valid, here's access token             │
└─────────────────────────────────────────────────────────┘
                      ↓

Step 8: Backend gets user info and creates JWT
┌─────────────────────────────────────────────────────────┐
│ Backend creates JWT token for user                     │
│ Saves user to database                                │
└─────────────────────────────────────────────────────────┘
                      ↓

Step 9: Backend redirects to VERCEL with JWT token
┌─────────────────────────────────────────────────────────┐
│ Backend sends redirect:                                │
│ https://ai-crmsite.vercel.app/oauth2/callback?        │
│   token=eyJhbGciOiJIUzI1NiIs...                       │
│ ↑ Backend sends JWT back to Vercel frontend           │
└─────────────────────────────────────────────────────────┘
                      ↓

Step 10: Frontend receives JWT and loads dashboard
┌─────────────────────────────────────────────────────────┐
│ Frontend: OAuth2Callback.jsx                           │
│ Gets JWT from URL                                      │
│ Stores JWT in Redux                                    │
│ Calls GET /api/users/me with JWT                       │
│ Gets user profile                                      │
│ Redirects to /dashboard                                │
│ ✅ User is logged in!                                  │
└─────────────────────────────────────────────────────────┘
