ARCHITECTURE DECISIONS
================================================================================

1. Modal for Create/Edit (NOT separate pages)
   - Better UX than separate routes
   - Follows Projects pattern
   - Faster navigation

2. Redux + React Query
   - Redux for UI state (filters, viewMode, selectedCampaign)
   - React Query for server state (campaigns data)
   - Follows CRM pattern
   - Supports optimistic updates

3. Zod for Validation
   - Already used in crmSchemas.js
   - Type-safe validation
   - Good error messages

4. Toast Notifications
   - react-hot-toast already integrated
   - No additional setup needed
   - Consistent with CRM

5. Single Service File
   - services/leadMagnetService.js
   - All API calls in one place
   - Easy to mock for testing
   - Follows crmService.js pattern
