1. PUBLIC ROUTE STRUCTURE
================================================================================

INCORRECT (old):
  /forms/:publicToken

CORRECT (new):
  /m/:publicToken/:slug

EXAMPLES:
  /m/AbC123xyz/free-crm-guide
  /m/xY9zZq2Kk/email-automation-guide
  /m/pOlKjHgF2/saas-onboarding-checklist

RATIONALE:
- Matches backend URL design
- SEO-friendly (slug in URL)
- Memorable and shareable
- Allows future expansion (/m/ namespace)
- Can add /m/a/ for AI resources, /m/e/ for email, etc.

FRONTEND ROUTE:
  <Route path="/m/:publicToken/:slug" element={<PublicFormPage />} />

FRONTEND WILL:
  - Extract publicToken from URL
  - Extract slug from URL (for display/validation)
  - Call backend: GET /api/public/lead-magnets/{publicToken}
  - Display campaign based on publicToken
  - Validate slug matches campaign slug
  - Show 404 if slug doesn't match

5. CREATE / EDIT PAGE SPECIFICATIONS
================================================================================

IMPLEMENTATION: Modal (not separate page)
COMPONENT: LeadMagnetModal.jsx
SHARED FORM: LeadMagnetForm.jsx

FORM FIELDS (in order):

1. Campaign Name (required)
   - Type: Text input
   - Max length: 255
   - Placeholder: "e.g., Free CRM Guide"
   - Validation: Required, max 255 chars
   - On change: Auto-generate slug (if not manually edited)

2. Slug (required, auto-generated but editable)
   - Type: Text input
   - Max length: 100
   - Placeholder: "free-crm-guide"
   - Validation: Required, lowercase, alphanumeric + hyphens only
   - Logic:
     * Auto-generate from name on first input
     * Stop auto-generation if user manually edits
     * Validate uniqueness: POST /api/workspaces/{id}/lead-magnets/validate-slug
     * Show: "✓ Available" or "✗ Already in use"
   - Real-time validation as user types

3. Description (optional)
   - Type: Text area
   - Max length: 1000
   - Placeholder: "Describe your lead magnet..."
   - Rows: 4
   - Character count: "250/1000"

4. Status (optional)
   - Type: Toggle switch
   - Label: "Active"
   - Default: ON (active)

BUTTONS:
  ├─ Save (primary, full width)
  ├─ Cancel (secondary)
  └─ Unsaved Changes Dialog: "You have unsaved changes. Discard?"

MODAL LAYOUT:
  - Title: "Create Lead Magnet" or "Edit Lead Magnet"
  - Size: 500px max-width
  - Close button (X)

VALIDATION:
  ✓ Client-side: Zod schema
  ✓ Server-side: Backend validation
  ✓ Slug uniqueness: Real-time via API
  ✓ Show validation errors below fields
  ✓ Disable Save button until form is valid

AUTO-SLUG GENERATION:
  ```
  "Free CRM Guide" → "free-crm-guide"
  "Email Automation (2024)" → "email-automation-2024"
  "Lead Scoring 101!" → "lead-scoring-101"
  ```

SLUG VALIDATION:
  - Lowercase only
  - Alphanumeric + hyphens only
  - No spaces, underscores, or special chars
  - Min 3 chars, max 100 chars
  - Show error: "Only lowercase letters, numbers, and hyphens allowed"

LOADING STATE:
  - Save button shows spinner
  - Form disabled during submit

ERROR STATE:
  - Toast error: "Failed to save campaign"
  - Show field error if slug not unique

SUCCESS STATE:
  - Toast: "Campaign created/updated successfully"
  - Close modal
  - Refresh list page
