================================================================================
ARCHITECTURE DECISIONS
================================================================================

1. SERVICE LAYER
   - Single responsibility per function
   - Consistent naming (verb + noun)
   - Unwrap pattern for response handling
   - Error propagation to components

2. VALIDATION
   - Zod for schema validation
   - Client-side validation for UX
   - Server-side validation for security
   - Field-level error messages

3. STATE MANAGEMENT
   - Redux for UI state (filters, sorting, pagination)
   - React Query for server state (data fetching)
   - Both patterns already established in codebase

4. COMPONENT STRUCTURE
   - Modular and reusable components
   - Separation of concerns (form, table, cards)
   - Props-based customization
   - Container/presentation pattern

5. STYLING
   - Tailwind CSS only (no new dependencies)
   - Consistent color scheme with existing codebase
   - Dark mode support throughout
   - Responsive design using Tailwind breakpoints

6. PERMISSIONS
   - useWorkspaceRole hook for permission checks
   - OWNER/ADMIN can create, edit, delete
   - ALL members can view
   - Public routes don't require authentication
