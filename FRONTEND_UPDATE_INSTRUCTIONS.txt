================================================================================
                      COMMON ISSUES
================================================================================

ISSUE: Still seeing old metrics layout
SOLUTION: Hard refresh (Ctrl+Shift+R) or clear browser cache

ISSUE: Tabs don't appear
SOLUTION: Make sure you have lucide-react installed
  Command: npm install lucide-react
  
ISSUE: Styles look broken
SOLUTION: Tailwind CSS not loading
  1. Check crm-frontend/src/index.css exists
  2. Verify Tailwind is imported in main.jsx
  3. Restart dev server
  
ISSUE: Seeing blank page
SOLUTION: 
  1. Check browser console for errors (F12)
  2. Check terminal for build errors
  3. Clear node_modules and reinstall:
     rm -r node_modules
     npm install

ISSUE: Changes not reflecting
SOLUTION:
  1. Verify file was saved (check git diff)
  2. Restart dev server
  3. Hard refresh browser
  4. Check if file path is correct
